# EBT Target Map

Target-area datasets and editing tools for [EBT Dot Safari](https://github.com/ShortOkapi/ebt-dot-safari), covering the curated Euro-use map and a worldwide land model based on OpenStreetMap.

[Open EBT Target Map](https://shortokapi.github.io/ebt-target-map)

## Project Architecture

The tool is built as a static, single-page web application integrated with a Node.js GitHub Actions worker, strictly adhering to DRY principles.

*   **`core.js`:** The single source of truth for grid mathematics, data validation, and compaction logic. Wrapped in a Universal Module Definition (UMD), it is consumed by both the browser UI and the Node.js backend.
*   **`editor.js`:** The browser-based Leaflet application. It handles DOM manipulation, local storage draft management, rendering, and the GitHub API integration for publishing map updates.
*   **`compact.js`:** A Node.js script executed by GitHub Actions that imports `core.js` to process the raw map data into continuous, compressed coordinate ranges.
*   **`euro-use-master-map.json`:** The comprehensive, uncompressed source dataset containing all curated dots, editor history, timestamps, and comments.
*   **`euro-use-eligibility.json`:** The lightweight, compressed output file automatically generated by GitHub Actions for consumption by Dot Safari.

## The Editing Workflow

The map editor allows curators to visually assign eligibility statuses (Conquerable, Unconquerable, Sea, Foreign, Unreviewed) to specific geographic dots.

1.  **Local Editing:** Edits are made in the browser and automatically saved to `localStorage` as a working draft. Unfinished forms and comments are retained between sessions.
2.  **Reviewing:** Editors can generate a visual HTML Change Report summarizing their session's actions, which can be saved or shared.
3.  **Publishing:** Clicking "Publish" prompts for a GitHub Personal Access Token. The editor uses the GitHub API to push the updated `euro-use-master-map.json` directly to the `main` branch.
4.  **Automation:** The push triggers a GitHub Action (`compact-map.yml`) that runs `compact.js`, generating and committing a fresh `euro-use-eligibility.json` file.

## Local Development

To run the editor locally, you need a local server to bypass browser CORS restrictions for loading the local JSON files. 

1. Clone or download the repository.
2. Open a terminal in the project folder and start a Python HTTP server: `python -m http.server 8001`
3. Open your browser and navigate to `http://localhost:8001`.
